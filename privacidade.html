Política de Privacidade

Este site é um projeto acadêmico. O formulário da página "Testes" (dashboard.html) é estático: o atributo action="#" não envia dados a nenhum servidor, banco de dados ou serviço de terceiros.

Dados solicitados no formulário

Nome do sistema, configuração de CPU/GPU/RAM, tipo de teste, e-mail e observações. Esses campos existem apenas para fins didáticos de HTML e não são coletados, armazenados ou transmitidos.

Se este projeto for conectado a um backend

Caso uma versão futura passe a enviar estes dados a um servidor real, os princípios de Privacy by Design devem ser aplicados: coleta mínima, mascaramento ou hash de identificadores pessoais na entrada, consentimento explícito (já representado pela caixa de aceite do formulário) e um mecanismo de exclusão de dados mediante solicitação do titular, em conformidade com a LGPD.
